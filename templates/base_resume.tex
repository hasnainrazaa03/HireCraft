    HireCraft base resume template.

    Rendered by app/services/latex/renderer.py, which swaps Jinja's default
    delimiters for LaTeX-safe ones so they do not collide with TeX braces or
    percent comments. See that module's docstring for the exact syntax.

    NOTE: never write a closing comment delimiter inside a comment body - it
    terminates the block early and dumps the remaining prose into the document.

    Every interpolated value is escaped automatically. Do not add the `raw`
    filter to anything that originates from user data.

    layout, standard section headings, selectable text. Parsers read this in
    linear order, which is why the layout stays deliberately plain.
