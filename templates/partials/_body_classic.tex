((# ===================================================================
    Classic résumé body — the two-column-header, \resumeSubheading layout.

    Kept separate from partials/_body.tex because the difference is
    structural, not stylistic: this one puts contact details in a two-column
    tabular beside the name rather than centred under it, and lays every entry
    out through \resumeSubheading{left}{right}{sub-left}{sub-right} instead of
    \entryheading. A preamble alone can't turn one into the other.

    A template including this file MUST first define:
      \resumeSubheading{#1}{#2}{#3}{#4}
      \resumeItem{#1}  \simpleItem{#1}  \courseItem{#1}
      \resumeSubHeadingListStart / End, \resumeItemListStart / End
      colour `muted`, a \section format, and \begin{document}

    Every interpolated value is auto-escaped. Never add the `raw` filter to
    user data. Do not write a closing comment delimiter inside a comment.
   =================================================================== #))
